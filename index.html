⚙️ Cloudflare Worker Kurulumu

Sofascore verileri için ücretsiz bir Cloudflare Worker gerekiyor. Sadece bir kez kurarsın — 3-4 arkadaşın aynı Worker URL'sini kullanabilir, limit yok.

1. workers.cloudflare.com → ücretsiz hesap aç
2. Workers & Pages → Create Application → Create Worker tıkla
3. Worker'a bir isim ver (örn: sofascore-proxy), sonra aşağıdaki kodu tamamen sil ve yapıştır:
4. Save and Deploy tıkla
5. Sayfanın üstündeki Worker URL'sini kopyala
    (örn: https://sofascore-proxy.kullanici.workers.dev)
